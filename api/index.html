Quick Hadoop Terminal Commands

To run on an actual Hadoop cluster, run these standard commands in your terminal:

# 1. Create target HDFS input directory
hdfs dfs -mkdir -p /netflix/input

# 2. Upload Netflix CSV to HDFS block storage
hdfs dfs -put dataset/netflix_titles.csv /netflix/input/

# 3. Submit distributed MapReduce job using Hadoop Streaming JAR
hadoop jar $HADOOP_HOME/share/hadoop/tools/lib/hadoop-streaming-*.jar \
  -files hadoop/mapper.py,hadoop/reducer.py \
  -mapper "python3 mapper.py" \
  -reducer "python3 reducer.py" \
  -input /netflix/input/netflix_titles.csv \
  -output /netflix/output

# 4. View aggregated MapReduce output on HDFS
hdfs dfs -cat /netflix/output/part-* | head -n 20

HDFS Storage Architecture & ELT Data Pipeline

Detailed architectural breakdown of the Big Data pipeline from local storage to HDFS, Hive, and Reporting.

🏗️

End-to-End System Workflow

Stage 1

Raw CSV Ingestion

Kaggle Netflix dataset stored on local Linux file system (2.41 MB, 6,234 records).

➔
Stage 2

HDFS Block Storage

Uploaded via hdfs dfs -put to /user/hadoop/netflix/. Managed across DataNodes in 128 MB blocks.

➔
Stage 3

Hive External Table

Mapped via OpenCSVSerde (Schema-on-Read). Preserves raw data while handling embedded commas.

➔
Stage 4

Data Cleansing & ORC

ELT pipeline transforms nulls, splits compound duration, and stores in managed ORC table with Snappy compression.

➔
Stage 5

Analytical HiveQL

18+ distributed queries executed over Tez/MapReduce execution DAGs to yield insights.

📦
